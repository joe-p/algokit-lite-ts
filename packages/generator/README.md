# @joe-p/algokit-lite-generator

The algoKIT lite typed ARC56 app client generator and the `algokit-lite` CLI.

```sh
npx @joe-p/algokit-lite-generator <arc56.json> -o <output.ts>
```

Generated clients import from `@joe-p/algokit-lite-app-client` and `@joe-p/algokit-lite-composer`, so projects using them need both packages.

See the [algoKIT lite README](https://github.com/joe-p/algokit-lite-ts#readme) for documentation.
